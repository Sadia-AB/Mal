# Mal - Expense Tracker 

Mal is a personal expense tracker built to help users record their spending and keep track of their budget. 

## Features:

- Add expenses with a description and amount. 
- Validate inputs to prevent empty descriptions and invalid amounts.
- Delete individual expenses.
- Automatically calculate total spending and remaining budget. 
- Save expenses in the browser using `localStorage` , so they remain available after refreshing the page.
- Display a message when there aren’t any expenses. 

## Built with: 
- HTML
- CSS
- JavaScript 
- Browser localStorage
